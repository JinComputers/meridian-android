# «RU-адреса напрямую» — российские адреса, домены и приложения мимо VPN

Общий документ для всех клиентов: Android (сделано, кот 3), iOS (кот 4),
macOS / Windows (коты 5 и 6), панель роутеров (кот 2). Решение владельца
25.09.2026: один переключатель, который пускает российские сервисы мимо
туннеля.

## Зачем

Банки, госуслуги, маркетплейсы (Wildberries, Ozon, Яндекс Маркет) и многие
российские сайты не работают или работают хуже с зарубежного адреса, а
часть банков отказывается работать при включённом VPN вообще. Через
туннель им ходить незачем: VPN нужен для заблокированного, а не для своего.

## Что входит (три слоя, берите те, что умеет ваша платформа)

| Слой | Что | Android | iOS | macOS/Windows | Роутер |
|---|---|---|---|---|---|
| **Адреса** | российские блоки IPv4 мимо туннеля | да (маршруты) | да (`excludedRoutes`) | да (маршруты) | да (ipset/nftset, маршрут в WAN) |
| **Приложения** | российские приложения целиком мимо туннеля | да (`addDisallowedApplication`) | нет — iOS не умеет по приложениям | по процессам — если ваш механизм умеет | нет |
| **Домены** | российские домены мимо туннеля | нет — VpnService только адреса | нет без DNS-перехвата | да (ваш «белый режим + прямые домены») | да (dnsmasq/nftset по доменам) |

По умолчанию переключатель **выключен**. Человеку предлагается включить
его один раз, если на устройстве найдены российские приложения (Android).

## 1. Адреса

**Источник** — официальный реестр RIPE NCC `delegated-ripencc-latest`:
все блоки IPv4 со страной `RU` и статусом `allocated`/`assigned`. Это
страна *регистрации* блока, не геолокация: для «банки, госуслуги,
маркетплейсы» этого достаточно, но российская компания на зарубежном CDN
сюда не попадёт — для этого слой доменов.

**Генератор** — `tools/ru_ipv4.py` в `meridian-android-src`:

```
python tools/ru_ipv4.py --txt ru_ipv4.txt   # все блоки RU, CIDR построчно (для вас)
python tools/ru_ipv4.py                     # двоичный ru_ipv4.bin для Android
```

На 24.09.2026: **8650 блоков**, ~45 млн адресов. После `collapse` соседних
блоков. Обновлять раз в несколько месяцев (или при каждой сборке).

**Сколько маршрутов потянет платформа** — главное ограничение:

- **Android 13+**: `addRoute(0.0.0.0/0)` + `excludeRoute` на каждый блок.
  Все 8650 в один вызов к системе не лезут надёжно (предел размера
  передачи между процессами), поэтому берём блоки `/22` и крупнее —
  **5922 записи, 97,9 % российских адресов**.
- **Android 8–12**: исключений нет, маршруты строятся дополнением до RU.
  Из 5922 блоков дополнение дало бы ~16 тыс. маршрутов, поэтому берём
  только `/18` и крупнее: **2123 маршрута, ~66 % российских адресов**.
- **Если система не приняла маршруты** — туннель собирается без них, а
  человеку говорится «RU-адреса напрямую не применились на этом
  телефоне». Туннель без исключений лучше, чем никакого. Советую то же.
- **iOS**: `NEIPv4Settings.excludedRoutes`. Предел числа маршрутов в
  документации Apple не указан; начните с `/22` и крупнее (5922) и
  проверьте на устройстве, при отказе — `/20` (2230 блоков, 87 %).
- **macOS/Windows**: маршрутов в таблице ядра может быть сколько угодно,
  но добавление тысяч по одному медленное. Берите весь список (8650) и
  добавляйте пачкой (Windows — `CreateIpForwardEntry2` в цикле без
  `route.exe`; macOS — через routing socket, не `route add` на каждый).
- **Роутер**: `ipset`/`nftables set` держит все 8650 без проблем, это
  штатный способ (OpenWrt, Keenetic с Entware).

Шлюз/вход Meridian (62.76.231.231 и др.) может сам оказаться в российском
блоке. Это не мешает: сокеты до шлюза и так идут мимо туннеля.

## 2. Приложения (Android; для настольных — если умеете по процессам)

Список в `app/src/main/java/org/meridianvpn/app/RuDirect.kt`, `RU_APPS`.
**95 пакетов**, каждое имя сверено 25.09 по живой странице Google Play или
RuStore. Группы: банки/инвестиции/платежи (28), госуслуги и официальное
(10), маркетплейсы и магазины (21), Яндекс (13), связь (7), соцсети,
видео и сервисы (16).

Почему приложения, а не только адреса: многие банки проверяют сам факт
VPN на телефоне (Android: `NetworkCapabilities.TRANSPORT_VPN`, список
интерфейсов). Приложение, выведенное из туннеля, VPN не видит вовсе —
одних маршрутов банку мало.

Режим «через туннель только выбранные» (Android): российские приложения
и так идут мимо, если человек не выбрал их сам — его выбор не трогаем.

## 3. Домены (настольные и роутер)

Android по доменам не умеет. **Источник доменов — снимок ru-domains выше**
(819 суффиксов, покрывает весь список ниже). Список ниже — прежний
стартовый, оставлен для истории.
Совпадение по суффиксу (`*.ru` покрывает `sberbank.ru`, `gosuslugi.ru` и т. д.):

```
ru
su
xn--p1ai          # .рф
yandex.net
yandex.com
yastatic.net
yandexcloud.net
vk.com
vk.me
userapi.com
vkuser.net
mycdn.me
2gis.com
avito.st
wbstatic.net
```

Список намеренно короткий: только то, в чём я уверен. Дополнять по
жалобам «сайт X не открывается с VPN».

**Ловушка DNS, обязательна к учёту.** Если российский домен резолвится
через DNS туннеля (1.1.1.1/8.8.8.8 из Парижа), крупные сервисы с гео-DNS
отдадут зарубежный узел CDN, и трафик уйдёт в туннель, минуя правило по
адресам. Для доменов из списка резолвить **напрямую** (DNS провайдера или
77.88.8.8 Яндекса мимо туннеля) — тогда вернётся российский адрес, и его
поймает слой адресов.

## 4. Интерфейс

Android: строка в «Настройках» под разделами, в той же разметке, что
разделы (заголовок 17, подсказка 13, разделитель), переключатель справа:

- заголовок: **«RU-адреса напрямую»**
- подсказка: **«банки, госуслуги, маркетплейсы и российские сайты — мимо VPN»**
- при поднятом туннеле после переключения: «Туннель уже поднят —
  применится при следующем подключении» и кнопка «Сейчас»
  (переподключение).
- разовое предложение (если найдены российские приложения): заголовок
  «Российские сервисы мимо VPN?», текст «Банки, госуслуги и маркетплейсы
  часто не работают через VPN. Пустить мимо туннеля российские сайты и
  приложения (…)? Изменить можно в «Настройки → RU-адреса напрямую».»,
  кнопки «Да, мимо VPN» / «Не нужно».

Настольным клиентам: переключатель ставьте рядом с «белым режимом +
прямыми доменами» — по смыслу это его готовый пресет.
