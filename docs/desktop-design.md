# Meridian на компьютере: оформление по образцу Android

Для котов 5 (macOS) и 6 (Windows), интерфейс на Wails v3 (HTML/CSS/JS).
Цель — чтобы настольное приложение выглядело как Android-приложение:
та же планета, те же цвета, те же слова.

Источник правды — код Android, всё ниже снято с него (ссылки
`файл:функция`). Расходится этот документ с кодом — прав код.

Ресурсы лежат в [`design/desktop/`](../design/desktop/):

| Файл | Что это |
|---|---|
| `planet.js` | Планета — перенос `Planet.kt` на HTML `<canvas>`, все три состояния и анимация, 1:1 |
| `preview.html` | Живой образец главного экрана со всеми состояниями (открыть через любой локальный http-сервер: `python -m http.server` в этой папке) |
| `tokens.css` | Цвета, размеры, отступы, стили кнопок и полей в CSS-переменных |
| `planet-off.svg`, `planet-connected.svg` | Статичные кадры планеты 220×220 (для скриншотов, заглушек, магазинов) |
| `app-icon.svg` | Значок приложения с фоном (для `.ico` / `.icns`, растрируйте в нужные размеры) |
| `app-icon-transparent.svg` | Значок без фона — только сфера |
| `app-icon-192.png` | Значок Android как есть, 192×192 (для сверки) |
| `tray-mono.svg` | Одноцветный силуэт для трея / строки меню (`currentColor`) |
| `logo.png` | Исходный логотип, 480×480 |
| `icons/*.svg` | Значки кнопок: шестерёнка, назад, поделиться, удалить, ссылки VK, приложения, логи (поле 40×40) |

Анимированную планету **не** делаем Lottie или GIF: на Android она
рисуется кодом каждый кадр, и `planet.js` — тот же код. Так покой,
подключение и туннель не могут разойтись с Android.

## 1. Главный экран

### Расположение

Одна колонка, поля 16 px, промежуток между блоками 12 px
(`MainActivity.kt: TunnelScreen`):

```
┌──────────────────────────┐
│        (распорка)        │  ← равные распорки сверху и снизу:
│                          │    планета всегда в середине по высоте,
│         ПЛАНЕТА          │    сколько бы строк ни занял блок под ней
│        220 × 220         │
│                          │
│      блок доступа        │  ← кнопки «Начать 3 дня…», «Купить ключ»,
│                          │    «Уже есть ключ?» — только когда доступа нет
│   строка состояния       │  ← 13 px, по центру; обычно ПУСТА
│        (распорка)        │
│            ⚙             │  ← шестерёнка 40×40, по центру внизу
└──────────────────────────┘
```

На главном экране ровно три вещи: планета, доступ, шестерёнка. Надписей
«Отключено» / «Подключено», версии, лога на нём **нет** — это решено
намеренно (Android, задачи 51 и 54): состояние показывает сама планета.

### Планета — она же кнопка

Отдельной кнопки включения нет. Нажатие на планету:

| Сейчас | Нажатие |
|---|---|
| выключено | подключить |
| подключение | **остановить подключение** (Android 0.1.155) |
| подключено | отключить |
| нет доступа (нет ключа, триал кончился) | не нажимается; что делать — объясняет блок доступа под ней |

Ряби/подсветки при нажатии нет: откликом служит сама планета — она сразу
начинает вращаться. Курсор над ней — `pointer`.

Для экранного диктора (`planet.js` ставит сам): «Планета Meridian,
кнопка подключения», состояние «отключено» / «подключаюсь» /
«подключено» / «недоступно»; действие «подключить» / «остановить
подключение» / «отключить».

### Как нарисована

Поле `S×S` (на Android `S = 220 dp`), центр `c`, радиус `r = 0.42·S`
(остаток поля нужен спутнику, он бежит по самому контуру).

1. Тело сферы — круг радиуса `r`.
2. Три меридиана — эллипсы высотой `2r` и шириной `2r·|cos(φ + i·60°)|`,
   `i = 0,1,2`, линия `0.022·r`. Меридиан уже толщины линии не рисуется.
3. Контур — окружность `r`, линия `0.045·r`.
4. Две точки на полюсах, радиус `0.075·r`.
5. Спутник (только в движении) — точка `0.85 · 0.075·r` на контуре,
   угол `t · скорость`, всегда цвета `#6F98FF`.
6. Вспышка, когда спутник проходит полюс: при `|cos(угол)| < 0.30`,
   `k = 1 − |cos|/0.30`, `g = k²`; радиальный градиент от полюса радиусом
   `точка · (2.4 + 2.2g)`: белый с прозрачностью `0.95g` → `0.30g` →
   прозрачный; поверх белое ядро `0.9·точка` с прозрачностью `g`.

Фаза меридианов `φ = 1.274 + 0.33·t` (рад). При `t = 0` (1.274 рад = 73°)
сфера выглядит в точности как логотип. `t` — секунды с начала движения;
сбрасывается в ноль **только** при остановке (переход «подключение →
подключено» движение не прерывает). В покое кадры не запрашиваются вовсе.

### Четыре состояния

| Состояние | Сфера | Контур и полюса | Меридианы | Движение | Под планетой |
|---|---|---|---|---|---|
| **выключено** | `#000000` (сливается с фоном) | `#3A4358` | `#272D3A` | нет, фаза покоя | пусто |
| **подключение** | `#000000` | `#3A4358` | `#272D3A` | меридианы едут (оборот ~19 с), спутник **быстро**: 2.62 рад/с, оборот ~2,4 с, вспышка ~0,23 с раз в 1,2 с | пусто |
| **подключено** | `#171C26` | `#6F98FF` | `#525D80` | меридианы едут, спутник **спокойно**: 0.78 рад/с, оборот ~8 с, вспышка ~0,8 с раз в 4 с | пусто |
| **ошибка** | как «выключено» | | | стоит | строка состояния, цвет `#6F98FF`, текст причины (раздел 4) + системное уведомление |

Цвет отвечает за «связь есть» (серая — нет, синяя — есть), скорость
спутника — за «работа идёт» (быстро — подключаюсь, спокойно — работаю).
Скорости и серые цвета совпадают с iOS (кот 4).

Отдельного «красного» состояния ошибки нет: планета просто
останавливается, а причину говорит строка под ней. Строка исчезает при
следующем удачном подключении.

## 2. Цвета, шрифты, размеры

Тема **одна, чёрная**. Светлой на Android нет, и это решение: фон чисто
чёрный. Если захотите светлую для компьютера — это новое решение
владельца, образца нет.

|---|---|---|
| `space` | `#000000` | фон окна; тело планеты без связи |
| `sphere` | `#171C26` | тело планеты при туннеле; разделители строк; подложка нижней панели |
| `edge` | `#6F98FF` | акцент: кнопки с заливкой, текстовые кнопки, значки разделов, строка-ошибка, спутник |

| `meridianOff` | `#272D3A` | меридианы без связи |

Цвета **логотипа** другие (значок стоит на своём фоне): фон `#0A0C11`,

### Элементы Material в теме приложения (`MainActivity.kt`)

- Поле ввода: контур `#7C859E`, в фокусе `#6F98FF`, подпись над полем.
- Флажки, переключатели, радиокнопки — акцент `#6F98FF`.

### Шрифт

Системный (на Android — Roboto, отдельного шрифта нет). На компьютере
тоже системный: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.

| Размер | Где |
|---|---|
| 20 | заголовок экрана: «Настройки», «Логи», «Обход белых списков» |
| 17 | заголовок строки настроек; заголовок «Раздельное туннелирование» |
| 16 | обычный текст (bodyLarge) |
| 14 | строка доступа в настройках; раскрывашка «Как получить ссылки» |

| 12 | статус ссылки VK; строки лога; версия |
| 11 | сама ссылка VK в списке |

Жирный только у объявления «Вышла версия …» и у строки версии, когда

ссылки VK / приложения / логи (`#6F98FF`). Концы линий скруглены.

(силуэт одним цветом: на macOS как template image, на Windows белый на
тёмной панели задач, чёрный на светлой).

## 3. Настройки: что переносится на компьютер

### Экраны Android

Главный → ⚙ «Настройки» → разделы. Каждый экран: сверху стрелка «назад»
и заголовок, «назад» возвращает туда, откуда пришли.

**«Настройки»** (`SettingsScreen.kt`) — список разделов, внизу строка
доступа и версия:

| Раздел Android | Подсказка под ним | На компьютере |
|---|---|---|
| Раздельное туннелирование (значок «приложения») | «мимо туннеля, выбрано N» / «через туннель, выбрано N» | **нет как есть.** Выбор приложений на Android делает система; на компьютере вместо него — белый режим и прямые домены (ниже) |
| Обход белых списков (значок «ссылки») | «ссылки на звонки, через них работает запасной путь» | **да**, экран целиком |
| Логи (значок «логи») | «что происходило внутри» | **да**; вместо «поделиться» — «сохранить в файл» / «открыть папку» |
| строка доступа внизу | «Доступ до дд.мм.гг» / «Бессрочный ключ» / «Пробный период: осталось …» | **да** |
| ключ: «Купить ключ», «Уже есть ключ?», поле «Ключ», «Проверить» | | **да** |
| «Перенести на это устройство» | | **да**, если API позволяет перенос для компьютера — спросить кота 1 |
| «Начать 3 дня бесплатно» | | **решение владельца**: пробный период выдаётся на устройство |
| версия и обновление («0.1.N · это последняя», «→ 0.1.M · обновить») | | **да**, своим механизмом обновления; тексты те же |
| разрешение на уведомления | | нет (на Android это требование системы) |
| транспорт авто/прямой/релей, токен GitHub | | нет — только в отладочной сборке Android |

**Только на компьютере** (на Android этого нет, образца оформления нет —
делать в том же стиле, что строки раздела «Настройки»):

- **Белый режим + прямые домены** — вместо раздельного туннелирования.
  Предлагаемая строка: заголовок «Прямые домены», подсказка
  «белый режим, доменов N» (на Android «выбрано N»).
- **Автозапуск при входе** — строка с переключателем справа: заголовок
  «Запускать при входе», подсказка «туннель поднимется сам после входа в
  систему» (формулировку утвердить у владельца).

Ни одна настройка на Android не требует кнопки «Сохранить»: изменение
пишется сразу. Держитесь того же.

### Экран «Обход белых списков» (`HashScreen.kt`)

Сверху вниз: «назад» + «Обход белых списков» (20) · поле «Ссылка на
звонок» с подсказкой `https://vk.com/call/join/…` · кнопка на всю ширину:
«Добавить», если в поле есть текст, иначе «Проверить все»; во время
работы «Проверяю…» · строка хода проверки (13) · раскрывашка «▸ Как
получить ссылки» (14, `#6F98FF`) · разделитель · список ссылок: ссылка
(11, `#D7DCE8`), под ней статус и время проверки (12, `#7C859E`),
справа крестик «удалить».

## 4. Тексты интерфейса (русский, дословно)

### Главный экран, доступ (`AccessScreen.kt`)

| Когда | Текст |
|---|---|
| нет пробного, нет ключа | кнопка «Начать 3 дня бесплатно» (во время запроса «Минуту…») |
| | кнопка «Купить ключ» |
| | текстовая кнопка «Уже есть ключ?» (во время проверки «Проверяю…») |
| ввод ключа | поле «Ключ», кнопки «Проверить» / «Отмена»; короче 8 символов — «ключ слишком короткий» |
| пробный кончился | «Пробный период закончился. Пробный период даётся один раз на устройство.» |
| ключ занят другим устройством | кнопка «Перенести на это устройство» → «Перенести» / «Отмена» |

### Строка состояния под планетой (`Notice`)

Серая (`#7C859E`) — новость, синяя (`#6F98FF`) — плохая новость.

| Когда | Текст |
|---|---|
| ключ принят | «Ключ принят» / «Пробный период начался» / «Подписка активна» |
| ключ только что выдан | «Ключ выдан только что — серверу нужно до минуты» |
| включён приватный DNS | «Включён приватный DNS. Если сайты не открываются, переключите его на «Автоматически» в настройках сети» (Android-специфично) |
| нет сети | «Нет сети» |
| общий отказ | «Не удалось подключиться: <причина>» — причины: «сервер сейчас переполнен, попробуйте позже», «ключ не принят сервером», «сервер не ответил», «нет ключа доступа», «сеть сменилась во время подключения», «подключиться не удалось» |
| сдались после переподключений | «Связь потеряна: N попыток подряд не удались» |

### Причина отказа и что делать (`Paths.kt: failureAdvice`)

Показывается строкой под планетой **и** системным уведомлением с
заголовком «Meridian не подключился». Код причины даёт движок:
`engine.FailureKind()` (общий Go; на компьютере — прямой вызов пакета
`engine`, спрашивать сразу после того, как `desktop.Start` вернул
ошибку). Вместо «Настройки → Обход белых списков» подставьте путь к
своему экрану.

| Код | Текст |
|---|---|
| `blocked-nolinks` | «Сервер недоступен из этой сети напрямую — похоже, оператор включил белые списки. Обход через ВК-звонок не настроен: добавьте ссылку на звонок ВКонтакте в «Настройки → Обход белых списков»» |
| `blocked-linksdead` | «Сервер недоступен из этой сети напрямую — похоже, оператор включил белые списки. Все ссылки на ВК-звонки больше не работают: добавьте ссылку на звонок ВКонтакте в «Настройки → Обход белых списков», свежую» |
| `blocked-captcha` | «… ВКонтакте просит капчу: решите её из уведомления и подключитесь снова, или добавьте ссылку …, другую» |
| `blocked-links` | «… ВКонтакте не дал доступ по ссылкам на звонки: повторите позже или добавьте ссылку …, другую» |
| `blocked-relay` | «Сервер недоступен из этой сети ни напрямую, ни через ВК-звонок. Попробуйте другую сеть (например, Wi-Fi) или повторите позже» |
| `blocked` | «Сервер недоступен из этой сети. Попробуйте другую сеть (например, Wi-Fi) или повторите позже» |
| `silent` | «Сервер не узнал ключ. Если ключ получен только что — подождите минуту и подключитесь снова» |

Остановка подключения нажатием — **не** отказ: ни строки, ни уведомления.

### Настройки (`SettingsScreen.kt`)

«Настройки» · «Раздельное туннелирование» · «Обход белых списков» —
«ссылки на звонки, через них работает запасной путь» · «Логи» — «что
происходило внутри».

Строка доступа: «Доступ до дд.мм.гг» · «Бессрочный ключ» · «Ключ
работает, срок неизвестен» · «Ключ принят, проверяю подключением» ·
«Пробный период: осталось 2 дн 5 ч» (форматы: «N дн N ч», «N ч N мин»,
«N мин»).

Версия: «0.1.N» · «0.1.N · проверяю…» · «0.1.N · это последняя» ·
«0.1.N → 0.1.M · обновить» · «качаю 0.1.M · X из Y МБ» · «0.1.M готова ·
установить» · «проверить не удалось». Объявление на главном: «Вышла
версия 0.1.M» — кнопки «Обновить» / «Позже»; «Версия 0.1.M скачана» —
«Установить».

### Обход белых списков (`HashScreen.kt`)

Заголовок «Обход белых списков» · поле «Ссылка на звонок» · кнопки
«Добавить» / «Проверить все» / «Проверяю…».

Ход проверки: «проверять нечего» · «проверяю 2 из 4, осталось 2» ·
«проверено 2 из 4, пауза 5 с» · «готово: живых 3 из 4».

Статус ссылки: «не проверялась» · «живой» · «капча» · «мёртвый» ·
«релея нет».

«▸ Как получить ссылки» (раскрыто — «▾ …»):

1. «Открыть VK и перейти в сообщения» (синяя, нажимается — открывает VK)

5. «Вставить ссылку на звонок в поле выше»

## 5. Чего здесь нет и почему

- **Светлая тема** — на Android её нет.
- **Lottie / GIF планеты** — не нужен: `planet.js` рисует её тем же
  кодом, что Android.
- **PNG значка во всех размерах** — растрируйте `app-icon.svg` своим
  сборщиком (`.ico` — 16, 24, 32, 48, 256; `.icns` — 16…1024).
- **Размер окна** — на Android экран телефона. Для компьютера разумно
  узкое окно-колонка (например 380×640, как в `preview.html`); решение
  за котами 5/6 и владельцем.
