# Meridian

Гибридный VPN-клиент для Android

**Ключ доступа — у бота [@jincomputers_bot](https://t.me/jincomputers_bot).**

---

## Установка

1. Скачайте `meridian_0.1.XX.apk` из раздела **Releases** — берите самый верхний.
2. Откройте скачанный файл. Android спросит разрешение устанавливать
   приложения из этого источника — его нужно дать один раз.
3. Откройте приложение, начните пробный период или введите ключ.

Обновления ставятся **поверх**: настройки, ключ и выбранные приложения
остаются на месте. Удалять прежнюю версию не нужно и не следует —
удаление стирает ключ.

Приложение умеет проверять обновления само: в **Настройках** нажмите на
строку с номером версии внизу окна. Никаких уведомлений оно при этом не показывает.

Требуется Android 8.0 или новее. Поддерживаются arm64-v8a, armeabi-v7a и
x86_64 — одним файлом, выбирать не нужно.

## Проверка сборки

У каждого релиза в описании указана сумма SHA-256. Сверьте её со
скачанным файлом:

```
certutil -hashfile meridian_0.1.XX.apk SHA256     :: Windows
sha256sum meridian_0.1.XX.apk                      # Linux, macOS
```

Все сборки подписаны одним и тем же ключом. Сборку с
чужой подписью Android **не установит поверх** уже стоящего приложения —
он откажется сам, даже если файл выглядит настоящим. Само приложение
проверяет подпись ещё до установки и отказывается раньше системы.

Если приложение когда-нибудь попросит удалить прежнюю версию перед
установкой — **это не моя сборка**. Не ставьте её.

## Что приложение отправляет наружу

- **Проверка ключа доступа** — на наш сервер: сам ключ, идентификатор
  устройства и номер версии. Ничего больше.
- **Проверка обновления** — на GitHub, за файлом с номером последней
  версии. Без идентификаторов; GitHub при этом видит ваш адрес, потому
  что приложение работает мимо собственного туннеля.
- **Трафик туннеля** — на сервер VPN.

Логи остаются на устройстве и никуда не отправляются, пока вы сами их
не отправите кнопкой.
